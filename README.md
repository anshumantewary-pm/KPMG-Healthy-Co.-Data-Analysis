KPMG – Raw Data Analysis of Healthcare System
Project Overview

This project involves the analysis of raw healthcare data using Microsoft Excel, following a KPMG-style data analysis approach to understand the healthcare system.

Objective

Analyze raw healthcare data

Identify trends and patterns

Support data-driven insights

Tool Used

Microsoft Excel

Analysis Performed

Data cleaning

Sorting and filtering

Use of formulas and functions

Pivot tables and charts

Key Outcomes

Improved understanding of healthcare data

Identification of key trends and gaps

Simple insights for decision-making

Conclusion

This project shows how Excel alone can be used effectively to analyze raw healthcare data and generate meaningful insights.
